# Git practice for ST2195

This is a practice repository for ST2195 Programming for Data Science.
Do not clone this repository directly.
First fork it to your own GitHub account. Then clone your fork.

Four invented quarterly sales observations, measured in JPY thousands.
This is a teaching dataset, not actual business or student data.

Install Python with pandas and matplotlib, and install Quarto.
Run `python -m pip install pandas matplotlib` if the packages are missing.
Run `python analysis.py`, then `quarto render report.qmd`.
Open report.html. On macOS/Linux use python3 if required.

Files: data.csv (inputs), analysis.py (chart), report.qmd (report text).
chart.png and report.html are generated outputs and are not committed.
